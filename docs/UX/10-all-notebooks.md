# All notebooks

Extends Home ready (reference 09) with the same cream surfaces, teal book icons, rounded bordered cards and typography.

- Home → Your notebooks → View all opens a separate in-app All notebooks page; Home retains both carousel arrows and Add notes actions.
- Header: Back to home and All notebooks. Keep an explicit Create notebook button here as well as the circular (+) beside Your notebooks on Home. Creation uses the existing keyboard-safe modal.
- Show every notebook with its full wrapped title, actual source count and chevron. The list scrolls vertically; Home's viewport-fit requirement does not hide notebooks in this page.
- Tap a row to open its existing Sources/Study/History flow. Back to notebooks returns to All notebooks when entered from that page; Back to home returns to the compact home. Android Back follows the same hierarchy after closing any active modal/review.
- Empty state offers Create notebook. Busy imports prevent opening another notebook. Viewing, navigating or cancelling creation does not change notebook/source data.

No new images or dependencies; reuse existing icon assets. Native acceptance evidence belongs in state.md.
